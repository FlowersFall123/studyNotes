# 前端笔记

## 一、HTML 

### 1. 核心基础与文档结构

#### （1）文档结构规范

整体框架：每个 HTML 文档必须包含 `<html>` 根标签，内部分为 `<head>`（头部）和 `<body>`（主体）两部分，缺一不可。

- **`<head>`**：存放页面元数据，不直接显示在页面中，核心内容包括：
  - **`<title>`**：定义网页标题（显示在浏览器标签栏），如 `<title>我的第一个页面</title>`。
  - **`<meta>`**：描述文档属性，常见用途：
    - **字符编码**：`<meta charset="UTF-8">`（避免中文乱码，必须放在 `<head>` 最顶部）。
    - **视口设置**（适配移动端）：`<meta name="viewport" content="width=device-width, initial-scale=1.0">`。
    - **搜索优化**：`<meta name="keywords" content="HTML,前端">`、`<meta name="description" content="前端学习笔记">`。
  - **`<link>`**：引入外部资源，最常用场景是链接 CSS 文件，语法：`<link rel="stylesheet" href="style.css" type="text/css">`。
  - **`<style>`**：内嵌 CSS 样式，仅作用于当前页面，语法：`<style type="text/css">h1{color:red;}</style>`。
  - **`<script>`**：引入或定义 JavaScript 脚本，可放在 `<head>` 或 `<body>` 末尾（建议放在 `<body>` 末尾避免阻塞 DOM 渲染）。
- **`<body>`**：存放页面所有可见内容，如文字、图片、按钮、表格等，几乎所有内容标签都需包裹在 `<body>` 内（例外：`<frameset>`/`<noframes>`，用于框架页面，现已较少使用）。

#### （2）标签分类与特性

HTML 标签按显示方式分为 **块级标签** 和 **行级标签**（内联标签），两者特性差异直接影响页面布局：

| 类型         | 核心特性                                                     | 常见标签示例                                                 |
| ------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **块级标签** | 1. 独占一行，默认宽度为父容器 100%；2. 可嵌套块级或行级标签；3. 可设置宽高（width/height） | `<div>`（分区）、`<p>`（段落）、`<h1>-<h6>`（标题）、`<ul>`/`<ol>`/`<li>`（列表）、`<table>`（表格）、`<form>`（表单） |
| **行级标签** | 1. 同行排列，宽度由内容决定；2. 仅可嵌套行级标签；3. **不可**直接设置宽高 | `<span>`（范围）、`<a>`（超链接）、`<img>`（图片）、`<br>`（换行）、`<strong>`（加粗） |

**特殊标签**：空元素（无闭合标签），如 `<br>`（换行）、`<img>`（图片）、`<input>`（表单输入框），语法为 `<标签名 属性="值">`（无需 `</标签名>`）。

### 2. 关键功能标签详解

#### （1）超链接（`<a>` 标签）

实现页面内、页面间跳转及功能性操作，核心属性：

- **`href`**：指定链接目标，分为：
  - **绝对地址**：完整 URL，如 `<a href="https://www.baidu.com">百度</a>`（跳转外部网站）。
  - **相对地址**：基于当前文件路径，如 `<a href="pages/login.html">登录</a>`（跳转内部页面）。
  - **锚点链接**：跳转至页面指定位置，需先定义锚点 `<a name="top">顶部</a>`，再设置链接 `<a href="#top">回到顶部</a>`。
  - **功能性链接**：如打开邮箱 `<a href="mailto:xxx@xxx.com">联系我</a>`。
- **`target`**：指定打开方式，常用值：`_self`（当前窗口，默认）、`_blank`（新窗口）、`_parent`（父框架）。

#### （2）表单（`<form>` 标签）

用于收集用户输入并提交数据，核心属性：

- **`action`**：指定表单提交的后端 URL（如 `<form action="/api/submit" method="post">`）。
- **`method`**：提交方式，`get`（参数拼接在 URL，适用于简单查询，有长度限制）或 `post`（参数在请求体，适用于敏感数据，无长度限制）。

**核心子元素**：

- **`<input>`**：单标签，通过 `type` 属性实现不同输入类型，常见值：

| type 值    | 功能描述                     | 示例代码                                                 |
| ---------- | ---------------------------- | -------------------------------------------------------- |
| `text`     | 单行文本框                   | `<input type="text" placeholder="请输入姓名">`           |
| `password` | 密码框（输入内容隐藏）       | `<input type="password">`                                |
| `radio`    | 单选按钮（需同 name 值分组） | `<input type="radio" name="gender" value="男"> 男`       |
| `checkbox` | 复选框                       | `<input type="checkbox" name="hobby" value="读书"> 读书` |
| `submit`   | 提交按钮（触发表单提交）     | `<input type="submit" value="提交">`                     |
| `reset`    | 重置按钮（清空表单内容）     | `<input type="reset" value="重置">`                      |
| `file`     | 文件上传按钮                 | `<input type="file">`                                    |

- **`<textarea>`**：多行文本框，通过 `cols`（列数）和 `rows`（行数）控制大小，如 `<textarea cols="30" rows="5" placeholder="请输入备注"></textarea>`。

- **`<select>`**：下拉选择框，配合 `<option>` 子标签使用，如：

  ```
  <select name="city">
    <option value="" disabled selected>请选择城市</option>
    <option value="beijing">北京</option>
    <option value="shanghai">上海</option>
  </select>
  ```

#### （3）表格（`<table>` 标签）

用于展示结构化数据，核心子标签与属性：

- **基本结构**：`<table>`（表格容器）→ `<tr>`（行）→ `<th>`（表头单元格，默认加粗居中）/ `<td>`（普通单元格）。
- **高级属性**：
  - `colspan`：跨列，如 `<td colspan="2">跨2列</td>`（当前单元格占 2 列宽度）。
  - `rowspan`：跨行，如 `<td rowspan="3">跨3行</td>`（当前单元格占 3 行高度）。
- **语义化标签**：`<thead>`（表头区域）、`<tbody>`（表体区域）、`<tfoot>`（表尾区域），提升代码可读性与 SEO。

### 3. 规范与实用技巧

- **W3C 标准**：核心原则是“内容（结构）与表现（样式）分离”，即 HTML 仅写结构，CSS 控制样式；同时要求 HTML 语义化（如用 `<h1>-<h6>` 表示标题，而非 `<div style="font-size:24px;">`）。
- **XHTML 1.0 规范**：比 HTML 更严格，要求：标签名/属性名小写、标签必须闭合（如 `<br>` 需写为 `<br />`）、属性值必须加引号（单/双引号均可）、标签嵌套正确（不可交叉嵌套）。
- **特殊符号**：HTML 中部分符号需用实体表示，避免解析错误：
  - 空格：` `
  - 小于号 `<`：`<`
  - 大于号 `>`：`>`
  - 双引号 `"`：`"`
  - 版权符号 ©：`©`
- **调试技巧**：浏览器中右键“查看网页源代码”可查看 HTML 结构；按 F12 打开“开发者工具”，在“Elements”面板实时修改 HTML/CSS，辅助调试布局问题。

## 二、CSS (网页样式美化)

### 1. 样式引入方式

CSS 样式可通过 4 种方式引入，优先级从高到低为：**行间样式 > 内嵌样式 > 外部引入 / 导入样式**（就近原则，后定义的样式会覆盖先定义的同名样式）。

| 引入方式     | 语法示例                                                     | 适用场景                          |
| ------------ | ------------------------------------------------------------ | --------------------------------- |
| **行间样式** | `<div style="color: red; font-size: 16px;">内容</div>`       | 单个元素的临时样式调整            |
| **内嵌样式** | 在 `<head>` 中写 `<style type="text/css">div{color: red;}</style>` | 单个页面的样式定义                |
| **外部引入** | `<link rel="stylesheet" href="css/style.css" type="text/css">` | 多页面共享样式（**推荐**）        |
| **导入样式** | 在 `<style>` 中写 `@import url("css/style.css");`            | 从其他 CSS 文件导入样式（较少用） |

> **注意**：`@import` 需写在 `<style>` 开头，且末尾必须加 `;`。

### 2. 选择器：定位元素的“工具”

#### （1）基础选择器

- **标签选择器**：`标签名 { ... }`，如 `p{color: #333;}`（选中所有 `<p>`）。
- **类选择器**：`.类名 { ... }`，如 `.box{width: 100px;}`（选中所有 `class="box"` 的元素）。
- **ID 选择器**：`#ID名 { ... }`，如 `#header{height: 80px;}`（选中 `id="header"` 的唯一元素）。
- **通配符选择器**：`* { ... }`，如 `*{margin: 0; padding: 0;}`（清除默认边距）。

#### （2）复合选择器

- **后代选择器**：选中父元素内的所有子元素（空格分隔），如 `ul li{list-style: none;}`（选中所有 `<ul>` 内的 `<li>`）。
- **子选择器**：选中父元素的直接子元素（`>` 分隔），如 `div > span{color: blue;}`（仅选中 `<div>` 的直接子 `<span>`，不包括孙辈）。
- **类选择器 + 标签选择器**：限制类选择器的标签范围，如 `p.text{font-weight: bold;}`（仅 `<p>` 标签中 `class="text"` 的元素生效）。
- **多选择器共用样式**：用逗号分隔多个选择器，如 `h1, h2, h3{color: #666;}`。

### 3. 核心样式规则

#### （1）盒模型：控制元素的“空间占用”

每个 HTML 元素都可视为一个“盒子”，由内到外分为：**内容区 (content) → 内间距 (padding) → 边框 (border) → 外间距 (margin)**。

- **width/height**：默认控制内容区宽度/高度（若设置 `box-sizing: border-box`，则包含 padding 和 border）。
- **padding**（内间距）：
  - 1 个值：`padding: 10px;`（上下左右均为 10px）。
  - 2 个值：`padding: 10px 20px;`（上下 10px，左右 20px）。
  - 4 个值：`padding: 10px 20px 30px 40px;`（上→右→下→左，顺时针）。
- **margin**（外间距）：取值方式同 `padding`。特殊值：`margin: 0 auto;`（水平居中，需设置宽度）。
- **border**（边框）：需同时设置宽度、样式、颜色，如 `border: 1px solid #ccc;`。

#### （2）字体与文本样式

- **font-family**：字体家族，如 `font-family: "微软雅黑", sans-serif;`。
- **font-size**：字体大小，如 `16px` (默认), `1.2em` (相对父元素)。
- **font-weight**：字体粗细，`normal`, `bold`, `600`。
- **color**：文本颜色，`red`, `#ff0000`, `rgb(255,0,0)`。
- **text-align**：水平对齐，`left`, `center`, `right`。
- **line-height**：行高，`24px` 或 `1.5`（倍数）。
- **text-decoration**：文本装饰，`none`（去除下划线），`underline`（下划线）。

#### （3）过渡与动画 (Transition)

实现元素样式的平滑变化。

- 语法：`transition: 属性 时长 曲线 延迟;`

- 示例：

  ```
  .box {
    width: 100px;
    transition: width 0.5s ease 0.2s;
  }
  .box:hover {
    width: 200px;
  }
  ```

## 三、Vue (渐进式框架)

### 1. Vue 基础

#### （1）环境搭建与实例创建

- **Vue 3.x 创建方式**：

  ```
  Vue.createApp({
    data() { return { msg: 'hello' } }
  }).mount('#app')
  ```

- **区别 Vue 2.x**：Vue 2 使用 `new Vue({ el: '#app', data: {} })`；Vue 3 要求 `data` 必须是函数。

#### （2）模板语法

- **文本插值**：`{{ msg }}`，支持表达式 `{{ 1 + 1 }}`。
- **HTML 插入**：`v-html="htmlContent"`（慎用，防 XSS）。
- **属性绑定**：`v-bind:属性名`，缩写为 `:属性名`（如 `:src="imgUrl"`）。
- **事件绑定**：`v-on:事件名`，缩写为 `@事件名`（如 `@click="handleClick"`）。

#### （3）响应式数据与数据处理

- **data()**：返回对象中的属性均为响应式数据。

- **methods**：定义方法，用于处理事件逻辑或数据计算（每次调用都执行）。

- **computed**（计算属性）：基于响应式依赖缓存计算结果，避免重复计算。

- **watch**（监听属性）：监听响应式数据变化，触发回调。

  ```
  watch: {
    user: {
      handler(newVal) { ... },
      deep: true // 深度监听
    }
  }
  ```

#### （4）指令系统

- **条件渲染**：
  - `v-if` / `v-else-if` / `v-else`：销毁/创建 DOM（惰性渲染）。
  - `v-show`：切换 `display: none`（适合高频切换）。
- **列表渲染**：`v-for="(item, index) in list" :key="index"`（**必须绑定 key**）。
- **样式绑定**：
  - Class: `:class="{ active: isActive }"` 或 `:class="[classA, classB]"`。
  - Style: `:style="{ color: textColor }"`。
- **表单绑定**（`v-model`）：实现双向绑定。
  - 修饰符：`.lazy`（失焦同步）、`.number`（转数字）、`.trim`（去空格）。

### 2. Vue 组件化

#### （1）组件注册

- **全局注册**：`app.component('MyComponent', { ... })`。

- **局部注册**：在父组件的 `components` 选项中注册。

  ```
  const Child = { ... };
  Vue.createApp({
    components: { 'child-component': Child }
  })
  ```

#### （2）父子组件通信

- **父传子 (Props)**：
  - 父组件：`<child :title="parentTitle"></child>`。
  - 子组件：`props: ['title']` 或对象形式 `{ title: String }`。
  - **单向数据流**：子组件不可直接修改 Props。
- **子传父 ($emit)**：
  - 子组件：`this.$emit('sendData', data)`。
  - 父组件：`<child @sendData="receiveData"></child>`。

### 3. Vue 高级特性

#### （1）Vue 动画

使用 `<transition>` 包裹元素，结合 CSS 类名控制：

- `v-enter-from` / `v-enter-active` / `v-enter-to`
- `v-leave-from` / `v-leave-active` / `v-leave-to`

#### （2）集成 Animate.css

```
<transition
  enter-active-class="animate__animated animate__bounceIn"
  leave-active-class="animate__animated animate__bounceOut"
>
  <div v-if="show"></div>
</transition>
```

#### （3）列表过渡

使用 `<transition-group>` 组件，需为每个列表项绑定 `key`。

```
<transition-group name="list" tag="ul">
  <li v-for="item in list" :key="item.id">{{ item.text }}</li>
</transition-group>
```
